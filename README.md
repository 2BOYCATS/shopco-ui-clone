# SHOP.CO – E-commerce Landing Page 🛒

หน้า landing page ของร้านเสื้อผ้า โคลนจาก design ใน Figma เพื่อฝึกเขียน HTML/CSS ให้ตรงกับแบบ และทำ responsive

🧷[Live Demo](https://2boycats.github.io/shopco-ui-clone/)

## 🛠 Tech Stack
- HTML5
- CSS
- JavaScript

## 🚀 วิธีรันโปรเจกต์
1. เปิดโฟลเดอร์โปรเจกต์ด้วย VS Code
2. ใช้ Live Server เปิดไฟล์ `index.html`

## 📝 หมายเหตุ 
- โปรเจกต์นี้ทำ Responsive ไว้ 2 รูปแบบ ได้แก่
- **หน้าจอทั่วไป (Desktop):** หน้าจอกว้างมากกว่า 768px
- **หน้าจอขนาดเล็ก (Tablet / Mobile):** หน้าจอกว้าง 768px ลงมา

ยังไม่ได้ปรับให้เหมาะกับขนาดอื่นโดยเฉพาะ เช่น หน้าจอมือถือขนาดเล็กมากหรือจอขนาดใหญ่พิเศษ จึงอาจพบ layout ที่ไม่สมบูรณ์ในบางขนาด

## 🔮 แผนพัฒนาต่อ
- พัฒนาการทำ Responsive ให้ดียิ่งขึ้น
